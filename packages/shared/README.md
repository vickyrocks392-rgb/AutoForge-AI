# Shared

## Purpose

The Shared package provides common types, interfaces, constants, and utility functions used across all apps, services, and packages in the AutoForge AI platform.

## Responsibility

- Define core TypeScript types and interfaces
- Provide shared constants and enumerations
- Implement reusable utility functions
- Establish base classes and abstract contracts

## Future Contents

- Core type definitions (Service, Workflow, Artifact, etc.)
- Shared interfaces for service contracts
- Enum definitions for service states, error codes, etc.
- Utility functions for logging, validation, serialization
- Base error classes and error handling utilities
