# Prompts

## Purpose

The Prompts package manages prompt templates, versioning, and rendering for AI agent interactions within the AutoForge AI platform.

## Responsibility

- Define and version prompt templates for each service
- Provide prompt rendering with context injection
- Manage prompt configuration and parameters
- Support prompt chaining and composition
