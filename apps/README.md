# Apps

## Purpose

This directory contains the runnable application entry points for the AutoForge AI platform. Apps serve as the interface between users and the underlying service layer.

## Responsibility

- Provide user-facing interfaces (API and Web)
- Handle authentication, authorization, and request validation
- Route requests to the appropriate services via the workflow engine
- Aggregate and present results to users

## Future Contents

- `api/` — REST/GraphQL API gateway for programmatic access
- `web/` — Web-based user interface for interactive use
